# Sample project: client intake

The project folder the Phase 1 kernel runs against (docs/memwise/17-build-plan.md, Phase 1 exit test).
Only the **check** step has full instructions; the other steps are placeholders until Phase 2.

```
memwise check examples/intake
memwise test  examples/intake
```

Tools used here are provided by the kernel's sample tool set (`gst.validate_gstin`, `intake.extract_fields`,
`email.send`); example cases stub their results.
